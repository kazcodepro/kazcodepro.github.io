# KAZ Portfolio

Portfolio de Kaz — Full-Stack Developer.

## Contact form
Le formulaire utilise Formspree pour envoyer les messages sans afficher l'adresse e-mail de Kaz sur le site.

1. Créer un formulaire sur https://formspree.io/
2. Récupérer l'identifiant du formulaire.
3. Dans `index.html`, remplacer `YOUR_FORM_ID` dans :
   `https://formspree.io/f/YOUR_FORM_ID`
4. Les messages pourront ensuite être reçus sur l'adresse configurée dans Formspree.
